# Pixel Perceptron Challenge

8×8の手書き数字（digits）を使い、64個の重みを手動で調整する教材です。
HTML / CSS / TypeScript + Vite。Reactや実行時のPythonは不要です。

## 操作と計算

- 左右のClassで0〜9を選択。初期状態は0と1。
- 重みは全部0から開始。各マス右端の△で+1、▽で−1。
- 整数重みにアプリ上の上下限はありません。BigIntを用い、int8の折り返しやNumberの整数精度喪失を防ぎます。
- 入力は **x_i = d_i / 16**（0〜1）。出力は Σ w_i x_i。バイアスはありません。
- 左右の寄与マップは w_i x_i。色だけを±10で飽和させます。
- 出力は小数第1位表示。不等号は丸める前の厳密値で判定します。丸めによって表示値が同じでも不等号になる場合があります。
- Another Sample：各クラスから1枚ずつ再抽出。同じ画像が再び出る場合があります。重みは保持。
- Evaluate：各クラスから重複なしでN枚を独立にランダム抽出し、Nペアを比較。Nは少ない方のクラスの枚数。
- SCORE = 100 ×「左の出力 < 右の出力」のペア数 / N。同値は不成功。全重み0なら0%。評価ごとにペアが変わります。
- 重み・画像・クラスが変わると古いSCOREを消し、現在のペアのGood / Badを表示。同値は空欄。
- Reset：重みのみ0に戻します。クラスと表示画像は保持します。
- クラス変更時は両画像を再抽出します。元実装同様、左右に同じ数字も選べます。

重みの数値と寄与は16分の1単位の整数として厳密に計算しています。
これは d_i / 16 を使う計算と等価です。黒い画素 d_i = 0 は常に寄与0です。
